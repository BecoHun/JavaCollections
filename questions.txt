    }

    }
    //  public int hashCode() {    return 42;    }

class MapDemo {
    public static void main(String[] args) {
        Map <Task, String> map = new HashMap<>();
        Task task = new Task("pay");
        Task task1 = new Task("pay");
        Task task2 = new Task("job");
        map.put(task, "shop");
        map.put(task1, "bill");
        map.put(task2, "clean");
        System.out.println(map.size());
    }

A collection size of 3
If you uncomment the hashCode() method, the collection size will be 2.
When the hashCode() method of the Task class is commented out, the implementation inherited from the Object class is used.
In this case, the hash code is defined as the address in the memory where the object is located.
Therefore, objects task and task1 will be hashed into different buckets, and both will be added to the collection.
When the hashCode() method is uncommented, task and task1 are hashed into the same bucket, and a collision occurs.
When the collision is resolved, they are defined as the same key, and the value is replaced by the key.

16.
What will be the result of running the code below?
class WeakKey {}
public class WeakHashMapDemo {
    public static void main(String[] args) throws InterruptedException {
        Map<WeakKey, Integer> weakMap = new WeakHashMap<>();
        WeakKey key1 = new WeakKey();
        WeakKey key2 = new WeakKey();
        weakMap.put(key1, 11);
        weakMap.put(key2, 21);
        Iterator<WeakKey> iterator = weakMap.keySet().iterator();
        System.out.print(gcAndSize(weakMap));
        key1 = null;
        System.out.print(" " + gcAndSize(weakMap));
        System.out.print(" " + iterator.hasNext());
    }
    static int gcAndSize(Map<WeakKey, Integer> map) throws InterruptedException {
        System.gc();
        Thread.sleep(1000);
        return map.size();
    }
}
2 1 true
When you get an iterator to iterate over the keys, the WeakHashMap contains two entries.
The map then changes structurally as one of the keys is discarded since it is not used outside the collection.
The keys set also changes, leaving only one element.
However, the iterator on it works correctly because the keys set is a hash table (a one-dimensional array), the reference to which remains unchanged.
Therefore, calling the hasNext() iterator method returns true.
